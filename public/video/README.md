# Видео для заставки

Файл `intro.mp4` подхватывается заставкой (`src/components/layout/Intro.jsx`)
сам — в коде для замены ничего трогать не нужно. Если файл убрать, фоном
встанет фотография первого экрана с медленным наездом.

**Сейчас здесь временный ролик** — Mixkit, лицензия Mixkit Free License:
можно использовать в коммерческих проектах без указания авторства, нельзя
перепродавать как сток. Замените на свой материал, когда он будет.

Где брать бесплатные ролики: mixkit.co, coverr.co, pexels.com/videos,
pixabay.com/videos. Платные и заметно лучше: artgrid.io, storyblocks.com,
elements.envato.com.

Что подойдёт:

- **формат** — mp4, кодек H.264 (его понимают все браузеры и айфоны);
- **звук** — не нужен, вырежьте дорожку: браузеры всё равно запускают
  автовоспроизведение только без звука;
- **длина** — 8–15 секунд, зациклится само;
- **размер кадра** — 1920×1080 достаточно, больше не нужно;
- **вес** — до ~8 МБ, иначе на мобильном интернете заставка будет пустой
  несколько секунд.

Пережать готовый ролик (нужен ffmpeg):

```
ffmpeg -i исходник.mov -an -vf scale=1920:-2 -c:v libx264 -crf 26 -preset slow -movflags +faststart intro.mp4
```
