# Фотографии

Сюда кладутся снимки для сайта. Пока папка пуста, на местах кадров стоят
серые заглушки нужных пропорций — вёрстка от этого не ломается.

## Как поставить свои фото

1. Скопируйте файл в эту папку, например `01.jpg`.
2. Откройте `src/data/content.js` и укажите путь в нужном месте:

   ```js
   { title: 'Утро в Заречье', place: 'Подмосковье, 2025', cat: 'morning', src: '/images/01.jpg' }
   ```

   Путь всегда начинается с `/images/` — папка `public` в адресе не пишется.

3. Сохраните файл. В режиме `npm run dev` страница обновится сама.

## Что стоит учесть

- Размер по длинной стороне — 2000–2400 px, качество JPEG около 80.
  Больше не нужно: страница станет тяжёлой, а разница не видна.
- Пропорция кадра задаётся полем `ratio` (`RATIO.portrait` — 4:5,
  `RATIO.landscape` — 3:2). Фото обрезается по центру.
- Формат `.webp` тоже работает и весит меньше при том же качестве.
