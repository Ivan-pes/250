# Сайт свадебного фотографа

Одностраничный сайт-портфолио на **React 19 + Vite**. Весь текст, цены и список
кадров вынесены в один файл данных, фотографий пока нет — на их местах стоят
серые заглушки нужных пропорций.

## Запуск

```bash
npm install     # один раз
npm run dev     # http://localhost:5173
npm run build   # сборка в dist/
npm run preview # посмотреть собранную версию
```

## Структура

```
index.html                    подключение шрифтов, мета-теги, точка монтирования
src/
  main.jsx                    вход в приложение
  App.jsx                     порядок секций на странице
  data/content.js             ВЕСЬ ТЕКСТ САЙТА: тексты, цены, вопросы, кадры
  styles/base.css             переменные, сброс, типографика, кнопки
  components/
    layout/                   Header, Footer
    sections/                 Hero, About, Process, Portfolio,
                              Reviews, Faq, Contact
    ui/                       Section, SectionHead, Reveal, Photo,
                              Button, Field, Lightbox
  hooks/                      useInView, useScrollSpy, useScrolled, useBodyLock
  lib/                        placeholder.js, submitLead.js, cx.js
public/images/                сюда кладутся фотографии
```

Правило одно: **секция отвечает за композицию, `ui/` — за повторяющиеся детали,
`data/content.js` — за содержание**. У каждого компонента рядом лежит свой CSS
(`Portfolio.jsx` + `Portfolio.css`), поэтому стили не растекаются по проекту.

## Как менять содержание

Почти всё правится в `src/data/content.js`:

| Что поменять | Где |
| --- | --- |
| Имя, телефон, почта, Telegram | `brand` |
| Пункты меню | `nav` |
| Заголовок первого экрана и цифры | `hero` |
| Текст «Обо мне» | `about` |
| Шаги съёмки и сроки | `process` |
| Кадры и разделы галереи | `portfolio` |
| Отзывы | `reviews` |
| Вопросы и ответы | `faq` |
| Поля формы | `contact` |

Убрать секцию целиком — удалить её строку в `src/App.jsx`. Поменять порядок —
переставить строки там же.

## Как поставить настоящие фотографии

1. Положите файл в `public/images`, например `01.jpg`.
2. В `src/data/content.js` укажите `src: '/images/01.jpg'` у нужного кадра.

Пропорция берётся из поля `ratio` (`RATIO.portrait` — 4:5, `RATIO.landscape` —
3:2), фото обрезается по центру. Пока `src: null`, на месте кадра остаётся серая
заглушка — подробности в `public/images/README.md`.

## Форма брони

Форма проверяет обязательные поля и показывает подтверждение, но **заявки пока
никуда не отправляются**: `src/lib/submitLead.js` только имитирует запрос. Чтобы
письма приходили, подставьте в этой функции адрес своего обработчика — внутри
лежит готовый пример для Formspree.

## Что внутри, кроме вёрстки

- Подсветка текущего раздела в меню при прокрутке (`useScrollSpy`).
- Появление блоков при скролле — один общий приём, компонент `Reveal`;
  при системной настройке «уменьшить движение» анимации отключаются.
- Галерея: разделы, догрузка по кнопке, просмотр кадра во весь экран
  с управлением клавишами `Esc` и `←` `→`.
- Доступность: ссылка «К содержанию», видимый фокус, `aria`-атрибуты
  у меню, аккордеона и формы, блокировка прокрутки под модальными слоями.
