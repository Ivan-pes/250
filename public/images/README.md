# Фотографии

Здесь лежат снимки сайта. У каждого кадра три вида: сам файл (`hero.jpg`),
уменьшенная копия для телефонов (`hero@sm.jpg`) и крошечное размытое превью,
которое видно, пока фото грузится, — оно хранится в `src/data/photos.js`.

**Сейчас здесь временные снимки с Unsplash.** Лицензия Unsplash разрешает
использовать их в коммерческих проектах без указания авторства, но для сайта
фотографа это заглушки — замените их своими работами.

## Как заменить фото

1. Положите свой файл вместо нужного, оставив имя: например `04-dance.jpg`.
2. Из корня проекта выполните `python3 scripts/photos.py` — скрипт сделает
   копию `@sm` и обновит превью в `src/data/photos.js`.
3. Если добавляете новый кадр под новым именем, впишите путь в
   `src/data/content.js`:

   ```js
   { title: 'Утро в Ла-Оротаве', place: 'Ла-Оротава, 2025', cat: 'morning', src: '/images/01-morning.jpg' }
   ```

   Путь всегда начинается с `/images/` — папка `public` в адресе не пишется.

## Что стоит учесть

- Размер по длинной стороне — 1500–2400 px, качество JPEG около 82.
  Больше не нужно: страница станет тяжёлой, а разница не видна.
- Пропорция кадра задаётся полем `ratio` в `content.js` (`RATIO.portrait` —
  4:5, `RATIO.landscape` — 3:2). Лишнее обрезается **по центру**, поэтому
  вертикальные снимки с телефона лучше кадрировать заранее, иначе рискуете
  потерять голову или ноги.
- Скрипту нужен Pillow: `pip3 install pillow`.
